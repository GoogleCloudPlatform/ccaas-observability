# CCAIPCallLog_call_ended

Markdown representation of the CCAIPCallLog_call_ended event schema.

## Schema Structure

| Field Path | Type | Description |
| :--- | :--- | :--- |
| `insertId` | `string` | Unique stable identifier for the log entry generated by the ingestion pipeline. |
| `jsonPayload.event` | `object` | Event wrapper containing name, GCS source, and milestone specific payload. |
| `jsonPayload.event.name` | `string` | The specific milestone event name. |
| `jsonPayload.event.gcs_source` | `string` | Source GCS URI of the raw metadata file. |
| `jsonPayload.event.payload` | `object` | Milestone-specific metrics and attributes payload. |
| `jsonPayload.event.payload.call` | `object` | Reference metadata for the call session. |
| `jsonPayload.event.payload.call.id` | `integer` | Unique identifier of the call session. |
| `jsonPayload.event.payload.call.type` | `string` | The channel/type of the call session. |
| `jsonPayload.event.payload.call.lang` | `string` | The ISO 689 language code used during the call session. |
| `jsonPayload.event.payload.call.status` | `string` | The outcome status of the call session, e.g. finished or abandoned. |
| `jsonPayload.event.payload.call.uuid` | `Nullable<string>` | UUID identifier of the call session. |
| `jsonPayload.event.payload.details` | `object` | Milestone-specific metrics and attributes payload for details. |
| `jsonPayload.event.payload.details.rating` | `Nullable<integer>` | Metric property: rating. |
| `jsonPayload.event.payload.details.feedback` | `null` | Metric property: feedback. |
| `jsonPayload.event.payload.details.fail_reason` | `string` | why the call failed, e.g. agent_no_answer or client_error |
| `jsonPayload.event.payload.details.fail_details` | `Nullable<string>` | Metric property: fail_details. |
| `jsonPayload.event.payload.details.sub_status` | `null` | Metric property: sub_status. |
| `jsonPayload.event.payload.details.disconnected_by` | `string` | Metric property: disconnected_by. |
| `jsonPayload.event.payload.details.wait_duration` | `integer` | Metric property: wait_duration. |
| `jsonPayload.event.payload.details.call_duration` | `integer` | Metric property: call_duration. |
| `jsonPayload.event.payload.details.hold_duration` | `integer` | Metric property: hold_duration. |
| `jsonPayload.event.payload.details.in_queue_wait_time_va` | `Nullable<array>` | Metric property: in_queue_wait_time_va. |
| `jsonPayload.event.payload.details.automation_redirection` | `Nullable<object>` | Metric property: automation_redirection. |
| `jsonPayload.event.payload.details.automation_redirection` | `object` | Metric property: automation_redirection. |
| `jsonPayload.event.payload.details.automation_redirection.percent_redirection` | `boolean` | N/A |
| `jsonPayload.event.payload.details.automation_redirection.redirection_group[].group_label` | `string` | N/A |
| `jsonPayload.event.payload.details.automation_redirection.redirection_group[].destination.type` | `string` | N/A |
| `jsonPayload.event.payload.details.automation_redirection.redirection_group[].destination.queue_id` | `Nullable<integer>` | N/A |
| `jsonPayload.event.payload.details.automation_redirection.redirection_group[].destination.lang` | `Nullable<string>` | N/A |
| `jsonPayload.event.payload.details.automation_redirection.redirection_group[].after_hours` | `boolean` | N/A |
| `jsonPayload.event.payload.details.automation_redirection.redirection_group[].ah_destination` | `null` | N/A |
| `jsonPayload.event.payload.details.has_virtual_agent_handle` | `boolean` | Whether the call had at least one virtual agent handle leg. |
| `jsonPayload.event.payload.details.has_human_agent_handle` | `boolean` | Whether the call had at least one human agent handle leg. |
| `jsonPayload.message` | `string` | N/A |
| `resource` | `object` | Google Cloud resource monitored resource metadata envelope. |
| `resource.type` | `string` | The monitored resource type identifier (always contactcenteraiplatform.googleapis.com/ContactCenter). |
| `resource.labels` | `object` | Monitored resource specific labels. |
| `resource.labels.location` | `string` | The GCP region/location of the ContactCenter resource. |
| `resource.labels.resource_container` | `string` | The GCP project ID hosting the ContactCenter resource. |
| `resource.labels.resource_id` | `string` | The identifier of the ContactCenter resource instance. |
| `timestamp` | `string` | Precise ISO UTC Z timestamp of the telemetry event. |
| `severity` | `string` | The severity level of the log entry (e.g. INFO, ERROR). |
| `logName` | `string` | The Google Cloud Logging resource path for the metadata log. |
