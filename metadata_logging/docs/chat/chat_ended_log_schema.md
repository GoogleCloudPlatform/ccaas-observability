# CCAIPChatLog_chat_ended

Markdown representation of the CCAIPChatLog_chat_ended event schema.

## Schema Structure

| Field Path | Type | Description |
| :--- | :--- | :--- |
| `insertId` | `string` | Unique stable identifier for the log entry generated by the ingestion pipeline. |
| `jsonPayload.event` | `object` | Event wrapper containing name, GCS source, and milestone specific payload. |
| `jsonPayload.event.name` | `string` | The specific milestone event name. |
| `jsonPayload.event.gcs_source` | `string` | Source GCS URI of the raw metadata file. |
| `jsonPayload.event.payload` | `object` | Milestone-specific metrics and attributes payload. |
| `jsonPayload.event.payload.chat` | `object` | Reference metadata for the chat session. |
| `jsonPayload.event.payload.chat.id` | `integer` | Unique identifier of the chat session. |
| `jsonPayload.event.payload.chat.type` | `string` | The channel/type of the chat session. |
| `jsonPayload.event.payload.chat.lang` | `string` | The ISO 689 language code used during the chat session. |
| `jsonPayload.event.payload.chat.status` | `string` | The outcome status of the chat session, e.g. finished or abandoned. |
| `jsonPayload.event.payload.details` | `object` | Milestone-specific metrics and attributes payload for details. |
| `jsonPayload.event.payload.details.rating` | `Nullable<integer>` | Metric property: rating. |
| `jsonPayload.event.payload.details.feedback` | `Nullable<string>` | Metric property: feedback. |
| `jsonPayload.event.payload.details.fail_reason` | `Nullable<string>` | why the chat failed, e.g. agent_no_answer or client_error |
| `jsonPayload.event.payload.details.fail_details` | `null` | Metric property: fail_details. |
| `jsonPayload.event.payload.details.sub_status` | `Nullable<string>` | Metric property: sub_status. |
| `jsonPayload.event.payload.details.disconnected_by` | `null` | Metric property: disconnected_by. |
| `jsonPayload.event.payload.details.wait_duration` | `integer` | Metric property: wait_duration. |
| `jsonPayload.event.payload.details.chat_duration` | `Nullable<integer>` | Metric property: chat_duration. |
| `jsonPayload.event.payload.details.hold_duration` | `null` | Metric property: hold_duration. |
| `jsonPayload.event.payload.details.in_queue_wait_time_va` | `null` | Metric property: in_queue_wait_time_va. |
| `jsonPayload.event.payload.details.automation_redirection` | `null` | Metric property: automation_redirection. |
| `jsonPayload.event.payload.details.has_virtual_agent_handle` | `boolean` | Whether the chat had at least one virtual agent handle leg. |
| `jsonPayload.event.payload.details.has_human_agent_handle` | `boolean` | Whether the chat had at least one human agent handle leg. |
| `jsonPayload.message` | `string` | N/A |
| `resource` | `object` | Google Cloud resource monitored resource metadata envelope. |
| `resource.type` | `string` | The monitored resource type identifier (always contactcenteraiplatform.googleapis.com/ContactCenter). |
| `resource.labels` | `object` | Monitored resource specific labels. |
| `resource.labels.location` | `string` | The GCP region/location of the ContactCenter resource. |
| `resource.labels.resource_container` | `string` | The GCP project ID hosting the ContactCenter resource. |
| `resource.labels.resource_id` | `string` | The identifier of the ContactCenter resource instance. |
| `timestamp` | `string` | Precise ISO UTC Z timestamp of the telemetry event. |
| `severity` | `string` | The severity level of the log entry (e.g. INFO, ERROR). |
| `logName` | `string` | The Google Cloud Logging resource path for the metadata log. |
